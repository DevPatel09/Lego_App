# Lego Set Management Web Application

A full-stack web application built with Node.js, Express.js, MongoDB Atlas, and EJS for managing LEGO sets. Users can browse, add, edit, and delete LEGO sets, as well as register and log in securely.

## 🚀 Live Demo
https://lego-app-o8uq.onrender.com/

## 📂 GitHub Repository
https://github.com/DevPatel09/Lego_App

---

## 📌 Features

- View all LEGO sets  
- Search LEGO sets by theme  
- View detailed information for a specific LEGO set  
- Add new LEGO sets  
- Edit existing LEGO sets  
- Delete LEGO sets  
- User registration and login  
- Session-based authentication  
- User login history tracking  
- Error handling for 404 and 500 pages  
- Fully deployed online using Render
