# **Lego App – Full-Stack Web Application Development**

A full-stack web application built with Node.js, Express.js, MongoDB Atlas, and EJS for managing LEGO sets. Users can browse, add, edit, and delete LEGO sets, as well as register and log in securely.

## 🚀 Live Demo
https://lego-app-o8uq.onrender.com/

### **Executive Summary**

Developed and deployed a scalable full-stack web application designed to manage LEGO inventory data through a centralized online platform. The application allows users to browse, search, add, update, and delete LEGO sets while providing secure user authentication through sign-up and login functionality. By integrating cloud hosting and a NoSQL database, the platform ensures accessibility, scalability, and efficient data management.

## **Business Problem**

Managing a large inventory of LEGO set data manually can be inefficient, time-consuming, and prone to inconsistencies.

Users required a centralized platform to:

- Store and manage **1,000+ LEGO set records** efficiently
- Perform secure **user registration and login**
- Search and filter sets quickly
- Perform CRUD operations seamlessly
- Access the application online without local installation

Without a centralized web application, managing and maintaining records would be difficult and less efficient.

## **Methodology**

### **1. Backend Development**

- Built server-side application logic using **Node.js** and **Express.js**
- Developed RESTful routes for CRUD operations
- Structured application using modular architecture for scalability
- Integrated middleware for request handling and authentication

---

### **2. Database Management**

- Integrated **MongoDB Atlas** for cloud-based data storage
- Stored and managed **1,000+ LEGO records** efficiently
- Connected backend routes to MongoDB collections for real-time data retrieval and updates

---

### **3. Frontend Development**

- Designed responsive UI using **HTML**, **Tailwind CSS**, and **EJS templates**
- Created dynamic pages for:
- Viewing LEGO sets
- Searching and filtering
- Adding / editing records
- User login / signup pages
- Improved user experience through clean layouts and intuitive navigation

### **4. Authentication System**

- Implemented **new user registration** functionality
- Built secure **login/logout system**
- Managed user sessions and restricted access to protected routes
- Improved application security and personalized access

### **5. Deployment**

- Deployed the application on **Render**
- Connected cloud-hosted backend with **MongoDB Atlas**
- Enabled online access and reliable performance
